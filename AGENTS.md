# AGENTS.md: working in the OASA brand repo

Read by AI coding agents (Claude Code, Codex, Cursor and others) and useful for people too. This repo holds OASA's logos, colors, art and branded documents.

## Rules

- **No weapons** in any art: no guns, missiles, weapon mounts, targeting or military insignia. Rugged, field-ready looks are fine.
- **Everything is a concept** until it's marked Official in the README. Don't mark anything Official.
- **Don't redraw or alter the logos.** Crop or resize them for a use, and keep the originals.
- **Brand basics:** Deep Navy `#0B253A`, Steel Blue `#253A66`, Signal Gold `#E3A32C`, Mesh Teal `#2F968A`, Aluminum `#E5E8ED`. Sora for headings, Inter for body text. Tokens in `tokens/`.
- **Documents** (`documents/`): edit the `.md` text first, then update the Word and PDF versions to match. Keep each document's README current.
- Art is CC BY-SA 4.0. The OASA name and logos are reserved (see `TRADEMARKS.md`). Note any AI-assisted or open-licensed parts in the pull request.

## Pull requests

Use the pull request template's checklist, include a preview image, and keep it to one topic. Writing style: short, clear, not wordy.
